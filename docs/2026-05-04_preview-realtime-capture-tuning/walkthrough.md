# 修正内容の確認

## 取得高速化

- `PREVIEW_CAPTURE_INTERVAL_MS` による待機を削除。
- 近接ターゲット差分（epsilon）による更新スキップを削除。
- これにより、キュー内の最新ターゲットを待機なしで順次処理する形に変更。

## シーク最適化

- プレビュー動画の時刻移動時に `fastSeek` が利用可能な環境では `fastSeek(time)` を利用。
- 非対応時は従来どおり `currentTime` を使用。

## 反映遅延の削減

- CSSの `left` トランジションを削除し、更新フレームを即時反映。

## 検証

- `yarn typecheck` 成功。
