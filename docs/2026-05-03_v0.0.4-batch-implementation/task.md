# タスク

## 目的
UrlViewer-App v0.0.4 として、以下を同時に改修する。

- ライブラリ/グループの選択・削除・ロック機能
- お気に入り固定グループと追加導線
- ライブラリ並び替え（動画名・動画長さ、昇降順）
- フッター廃止と右サイド常設ログ化
- プレイヤー操作性改善（シークプレビュー、キー操作、自動非表示、音量バー）
- プラグイン Git 導入失敗の可視化
- 閉じるボタンのアイコン分離（×）

## 受け入れ条件

- `dataVersion` は `3` になり、既存データが移行される
- `VideoItem.locked` / `VideoItem.durationSeconds` が利用可能
- `GroupItem.locked` / `GroupItem.builtin` が利用可能
- 「お気に入り」固定グループが自動補完され、削除不可
- ライブラリ画面に選択モードがあり、全選択/クリア/削除/ロックできる
- グループ画面にも選択モードがあり、削除/ロックできる
- ライブラリ並び替え（名前/長さ + 昇降順）が動作する
- 長さ未取得動画は長さソート時に末尾になる
- 右サイドでキューと実行ログを確認できる
- シークバー hover で時刻+プレビュー（不可時は時刻のみ）が出る
- シークバー選択時でも左右/J/K が動作し、左右は常に 5 秒移動
- 音量スライダーの 0〜現在位置が着色される
- 3秒無操作でコントローラーが非表示になる
- 再生時間テキストが選択されない
- Git プラグイン導入失敗時にメッセージが出る
