# タスクリスト

## 依頼内容
- 動画リストが名前ソートされているため、名前変更時に並び順が頻繁に入れ替わる問題を修正する。
- 動画名を1文字編集するたびに更新処理が走り、入力しづらくなる問題を修正する。
- リリース版アプリで Electron の上部メニューバーが表示される問題を修正する。
- 同一URLを再登録した際の重複判定（登録名違い含む）の現状を確認する。

## 完了条件
- ライブラリ一覧が「登録順（保存順）」で安定表示されること。
- 動画名編集は入力中に即保存されず、確定操作でのみ保存されること。
- リリース時にメニューバーが表示されないこと。
- 重複URL登録の現在仕様をコード根拠付きで説明できること。
