# implementation_plan

## 方針
1. 実行コードから旧入力変換依存を先に除去する。
2. 設定とレガシー互換文字列を除去する。
3. 最後にドキュメントを置換し、キーワード再検索で残存確認する。

## 実施手順
1. 旧オプショナル入力プラグイン本体を削除。
2. Renderer プラグインレジストリから静的登録を削除。
3. Builtin plugin catalog から旧入力系 seed を削除。
4. plugin manager の旧 plugin ID フィルタを削除。
5. 旧入力変換 alias を `tsconfig` / `vite` から削除。
6. 旧入力補助モジュールを削除。
7. `docs` に残る関連文言を中立表現へ置換。
8. 残存キーワードを `rg` で再検索。

## 検証
- 残存検索:
  - 旧入力変換機能に紐づく固有語
