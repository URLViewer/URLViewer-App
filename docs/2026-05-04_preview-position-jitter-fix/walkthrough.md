# 修正内容の確認

- 原因: 非同期のプレビュー取得完了時に、古いキャプチャ要求の `x/time` が `seekPreview` に再セットされ、最新カーソル位置との競合で左右ブレが発生していた。
- 対応:
  - 成功時: `setSeekPreview` は `imageDataUrl` のみ更新し、位置 (`x/time`) は維持。
  - 失敗時: `x/time` を上書きせず `visible` のみ維持。
- これにより、位置はホバーイベント側のみが制御し、プレビュー画像更新が遅れても位置が戻らなくなった。
