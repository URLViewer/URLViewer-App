# 実装計画（実施済み内容の整理）

## 1. 基盤整備
- 目的: Electronデスクトップアプリとしての実行基盤を確立する。
- 実施:
  - ViteプロジェクトをベースにElectron連携設定を追加。
  - `vite.config.ts` で main/preload/renderer のビルド経路を定義。
  - `package.json` に開発・品質・配布向けスクリプトを整備。

## 2. アーキテクチャ分割
- 目的: 責務分離と保守性を確保する。
- 実施:
  - `src/electron`: メインプロセス、preload、IPC、永続化、URL解決、updater抽象層。
  - `src/web`: feature-first UI実装とZustandストア。
  - `src/shared`: 共通型、zodスキーマ、既定値、入力パース関数。

## 3. ドメイン機能実装
- 目的: 入力値から動画視聴までのコア導線を実現する。
- 実施:
  - 複数入力・正規化・形式フィルタ。
  - `URL候補生成ロジック` による候補生成と順次到達性判定。
  - 最初に成功したURLのみ採用、全失敗時は候補を完全除外。
  - 同一動画タブの重複抑止（既存タブへフォーカス）。

## 4. UX実装
- 目的: 視聴・整理・設定変更を一画面で完結させる。
- 実施:
  - teal基調の明るいテーマをCSS変数 + Tailwindで適用。
  - ユニーク動画とグループ管理を別パネルで提供。
  - hls.jsプレイヤーにスキップ、再生速度、レジュームを実装。

## 5. 品質確認
- 目的: 最低限の回帰防止ラインを確保する。
- 実施:
  - Vitestでユニットテストを追加。
  - Playwrightで入力〜一覧反映のE2Eを追加。
  - `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm e2e`, `pnpm build` を通過確認。

## 注意
- `.codex/AGENTS.md` では yarn 利用方針だが、前回実装時点では `pnpm` ベースで構築済み。
  今後方針統一する場合は、ロックファイル/スクリプト運用の再調整を別タスク化する。
